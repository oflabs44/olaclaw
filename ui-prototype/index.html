olaclaw UI prototypes

Three directions for the chat screen. Each page is a working fake: type a message, send a second one during a reply to queue it, press Stop, and open Chats.

  • Workspace: the Overprint direction, calmer, as an assistant workspace with chats, running work, decisions, and routines.
  • Adire: indigo resist-dye cloth, text on undyed cotton.
  • Headline: what you ask is set as a headline, the answer is the copy.
  • Overprint: a two-ink print, pink and blue, slightly off register.
